# Project Raid API — Phase 1

Requires Windows 10/11 and .NET 10 SDK: https://dotnet.microsoft.com/download/dotnet/10.0

Double-click `run-local.bat`, or run `dotnet run --urls http://localhost:5080` in this folder.

Open http://localhost:5080/ and http://localhost:5080/health. The health endpoint only confirms the local development API is running; there are no accounts, passwords, matchmaking, or player data yet. Stop with Ctrl+C.
