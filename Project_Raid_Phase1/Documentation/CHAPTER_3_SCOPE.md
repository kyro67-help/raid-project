# Chapter 3 Season 1 preservation scope

Independent implementation inspired by Fortnite Chapter 3 Season 1 (The Flipped season).

Prioritize original recreations of POI concepts: Tilted Towers, Sanctuary, Daily Bugle, Sleepy Sound, Condo Canyon, Coney Crossroads, Greasy Grove, Rocky Reels, and Logjam Lumberyard. Gameplay targets: battle royale loop, storm phases, loot/inventory, weapons, vehicles, and original web-traversal mechanics. Support solo offline and online multiplayer, plus a custom launcher and UI.

Use original or properly licensed assets. Do not package Epic's Fortnite executable, proprietary assets, source code, backend, or extracted game files.

Build order: movement prototype; compact test area; loot/storm/elimination loop; expand island; dedicated server and matchmaking; launcher and polish.
