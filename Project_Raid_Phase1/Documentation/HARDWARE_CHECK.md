# Identify exact hardware on Windows

“AMD Ryzen 7 6000 HD series” is not an exact model. Ryzen 7 describes a CPU family; graphics may be integrated Radeon graphics or a separate GPU.

1. Press Ctrl+Shift+Esc.
2. Open Performance.
3. Select CPU and copy the full processor model.
4. Select GPU 0 (and GPU 1 if present) and copy the full GPU name.
5. Check Settings > System > About for Windows version.

Do not infer exact GPU or VRAM from the Ryzen family name alone.
