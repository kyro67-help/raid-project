# Project Raid — Phase 1 Roadmap

1. Verify PC hardware and Windows version.
2. Install Git, Visual Studio 2022 with C++ game development and .NET desktop workloads, and .NET SDK.
3. Initialize Git repository.
4. Run ASP.NET Core `/health` endpoint.
5. Resolve Unreal Engine installation.
6. Create Unreal Third Person C++ project.

Definition of done: Git repo has initial commit; backend starts locally and `/health` returns HTTP 200; Unreal project opens and launches a third-person test map.
