# Project Raid

Independent Chapter 3 Season 1-inspired preservation project.

## Phase 1 goals
- Establish a reproducible repository and project layout.
- Keep the launcher, backend, game client, and dedicated server separate.
- Build backend scaffolding while Unreal Engine installation is resolved.

## Technology
- Game client/server: Unreal Engine 5, C++ and Blueprints
- Launcher: C# / WPF
- Backend: ASP.NET Core
- Database: PostgreSQL (later phase)

## Important
Use original or properly licensed assets and code. Do not distribute Epic's proprietary Fortnite client, assets, extracted game files, or backend code.
